# Private operational monitoring

Keep production site inventories and generated reports off the public GitHub repository. Copy `config/sites.example.json` to `config/sites.private.json`, replace the fictional sites with approved canonical production URLs, and verify the file is ignored with `git check-ignore config/sites.private.json`. Run `node src/cli.js config/sites.private.json` from the repository root using Node.js 22 or newer. Results are written locally to `reports/latest-report.json`; that file is also gitignored. The monitor checks public HTTP availability, response time, TLS expiry and HTML form presence; it does not submit forms or verify delivery. Add sites only with authorization and distinguish previews from production domains. Do not publish live results, client inventories or credentials to GitHub Pages. Scheduled runs and alert delivery require a private runtime and have not been enabled by this change. A Git ignore rule is not access control; restrict local files and backups to authorized operators.
