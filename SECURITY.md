# Security policy

## Responsible monitoring

Run SiteCare only against websites you own or are authorized to monitor. The checker makes read-only page requests and should not be used to probe private systems, bypass access controls, or generate high request volume.

The public dashboard contains fictional sample data. Keep real client names, private URLs, credentials, and incident details out of a public repository.

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing credentials, private customer data, or exploit details.

Include the affected component, steps to reproduce, possible impact, and any suggested mitigation. Acknowledgment and remediation timing will depend on severity and reproducibility.
